# Référence visuelle retenue

La référence choisie est la **troisième piste bleu/jaune**, puis sa dernière révision avec un seul bandeau de scènes sous l'aperçu.

Maquette de conception, 1487 × 1058 pixels :
[Atelier Vululu — montage vidéo céramique](https://chatgpt.com/library?file_id=libfile_9f526bf5393c819185e06e8a313235b3&account_id=personal).

Ce lien nécessite le compte propriétaire ; un IDE ne peut pas en déduire un accès automatique. Le PNG n'est pas embarqué dans ce kit.
Le plan [studio-layout.svg](studio-layout.svg), les tokens et SCREENS.md sont utilisables sans accès à ChatGPT.
Si le PNG est rendu disponible localement plus tard, il complète ces contrats ; il ne remplace pas les critères fonctionnels et d'accessibilité.

## À préserver

- Atelier clair, bleu ultramarin, jaune rare.
- Navigation globale à gauche, projet et contexte en haut.
- Aperçu principal et **un seul** sélecteur de scènes dessous.
- Inspecteur contextuel droit, réglages avancés repliables.
- Versions et export visibles, pas de chat occupant tout le Studio.

## Ne pas recopier littéralement

Noma, céramique, nombre de scènes, textes, durées, sélection et photos sont des exemples.
Le rendu généré n'est pas une source exacte de police, couleurs ou composants ; tokens.json fait foi.
La maquette précédente « Studio vidéo pour Collection Terre » comporte une liste verticale de scènes en doublon : ne pas la prendre comme cible.
Le SVG est un plan documentaire original, pas la conversion ou l'édition du PNG généré.
